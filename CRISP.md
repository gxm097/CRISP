CRISP Source Code Components
=======
Research agent - searches vulnerability from a set of trusted domains in the web. 
Correlation Engine - gets vulnerabilities found by research agent and matches affected versions to the assets in the inventory to determine if the asset is potentionally vulnerable.
Analyst agent - looks at potential vulnerable assets are truly vulnerable.
Quality assurance agent - makes sure that its judgement is right to make sure no missing information and vulnerability is true.
Report generation - creates report.
